4. Remove the line `random.seed(...)`
5. Run the program again several times

Then explain:

## Task 3: utility `make_password.py`

Write a command-line utility that generates a random password.
This utility should be a CLI interface for the `make_password` function.

It must:
- run from the terminal
- allow users to specify constraints via command-line arguments

Supported parameters:
- `--min-digits`
- `--max-digits`
- `--min-uppercase`
- `--max-uppercase`
- `--min-lowercase`
- `--max-lowercase`
- `--min-punctuation`
- `--max-punctuation`

If an argument is not provided, use the default value from `make_password`.

After, the program should:
- read CLI arguments
- pass them to `make_password`
- print the generated password

Requirements:
- no input() usage
- only CLI arguments
- clear error messages on invalid input
- random order of characters
- output in a single line

Examples:
```
python make_password.py

python make_password.py --min-digits 3 --max-digits 5 --min-uppercase 2 --max-uppercase 4

python make_password.py --min-lowercase 6 --max-lowercase 6 --min-punctuation 1 --max-punctuation 2
